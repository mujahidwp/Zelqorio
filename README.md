## About

Zelqorio lets store owners edit simple and variable WooCommerce products from one modern dashboard.

- Spreadsheet-style product editor with variation rows
- Filters: category, tag, SKU, title, type, price range, stock, status
- Bulk price changes (fixed, amount, percent, sale rules, rounding)
- Bulk inventory and status changes
- Preview of old/new values before anything is saved
- Every saved value is reloaded from WooCommerce and verified
- Conflict detection and conditional undo for non-inventory fields
- Background processing with Action Scheduler when available
- Update-only CSV import and CSV export
- No license or account required, no telemetry, no external requests; max 2,000 selected items per operation

All product writes use WooCommerce CRUD objects. Designed to use WooCommerce APIs; HPOS compatibility requires runtime testing.

## Requirements

- WordPress 6.2 or higher
- Tested up to WordPress 7.1.4
- PHP 7.4 or higher
- WooCommerce (installed and active)

## How to install

1. In your WordPress dashboard go to **Plugins → Add New Plugin**.
2. Search for **Zelqorio**.
3. Click **Install Now**, then **Activate**.

Or download it directly from **[WordPress.org](https://wordpress.org/plugins/zelqorio/)**.
